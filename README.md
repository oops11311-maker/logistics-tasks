# 물류자동화팀 작업

물류자동화팀의 작업, 담당, 기한, 댓글, 알림을 한 서버와 한 데이터베이스에서 보는 웹 앱입니다. 휴대폰과 PC는 같은 주소를 쓰고, 설치형 PWA로도 열 수 있습니다. 화면과 HTTP API는 분리되어 있습니다.

GitHub 저장소가 공개라면 소스도 공개됩니다. 소스를 공개하고 싶지 않으면 저장소를 비공개로 바꾸세요. 앱에 쌓이는 작업 데이터는 공개로 두면 안 됩니다. 게시할 때는 비공개 또는 팀 공개만 선택하세요. 팀 공개가 없으면 비공개를 고르세요.

## 로그인과 초대

입구 로그인은 Cursor가 합니다. 이 앱은 비밀번호 화면을 두지 않습니다. 게시된 비공개 앱은 소유자와 소유자가 초대한 사람만, 팀 앱은 그 Cursor 팀의 사람만 열 수 있습니다. 게이트가 요청에 신원을 붙이고, 서버는 그 신원만 믿습니다.

Cursor 팀의 관리자/멤버와 이 앱의 역할은 다릅니다. 앱 역할은 관리자, 매니저, 멤버, 뷰어, 봇입니다. API 키(`kind: key`)는 사람이 아니므로 첫 관리자가 되지 않고 작업도 볼 수 없습니다.

구성원 표가 비어 있을 때 처음 들어온 사람이 관리자가 됩니다. 그 다음부터는 관리자가 이메일 또는 Cursor 식별자로 초대해야 합니다. 초대받지 않은 로그인 사용자는 막힘 화면과 모든 API `403`을 받습니다.

## 시간

일정은 Asia/Seoul 입니다. 시각 없는 마감일은 그 달력 날짜의 23:59:59.999 입니다. 영업일 기본은 월요일부터 금요일입니다. 휴일은 관리자가 ‘휴일 제외’를 켜기 전에는 빼지 않습니다.

## 봇

봇은 사람 관리자가 아닙니다. 호출 헤더는 이것 하나입니다.

```http
Authorization: Bearer <BOT_API_TOKEN>
```

비밀 이름은 `BOT_API_TOKEN`과 `SCHEDULER_TOKEN`입니다. 값은 서버 환경에만 두고, 저장소와 브라우저에 넣지 않습니다. 값이 없으면 봇 API는 열리지 않습니다. 기본 비밀번호는 없습니다.

봇은 범위 안의 작업을 읽고, 댓글과 알림과 요약을 씁니다. 담당자 변경, 기한 변경, 완료, 삭제(휴지통)는 `403`입니다. 작업 본문이나 댓글 안의 지시문은 권한을 바꾸지 않습니다.

## 예약 실행

브라우저를 닫아도 돌아가는 예약은 이 버전에 연결되어 있지 않습니다. 페이지 타이머로 대신하지 않습니다.

나중에 붙일 주소:

```http
POST /api/jobs/run
Authorization: Bearer <SCHEDULER_TOKEN>
```

관리자 세션으로도 같은 경로를 호출할 수 있고, 관리 화면의 ‘지금 실행’이 그 호출입니다. 슬롯 키로 같은 알림과 같은 반복 작업을 다시 만들지 않습니다. 기본 시각은 데이터베이스에 저장되며 관리자가 바꿀 수 있습니다.

- 평일 09:00: 오늘과 기한 지남 요약
- 마감 1일 전: 담당자 알림
- 기한 지남: 알림
- 진행 중인데 3영업일 무갱신: 확인 댓글과 알림
- 목요일 15:00: 주간 보고 초안
- 매일 00:10: 반복 작업의 해당 회차 생성

## 데이터

Postgres를 사용합니다. 스키마는 `migrations/`에 있고, 빌드가 적용한 파일은 다시 실행하지 않습니다. 재배포는 데이터를 지우지 않습니다. 이미 적용한 마이그레이션은 수정하지 않고 새 파일을 추가합니다. 컬럼을 지우거나 이름을 바꾸지 않습니다.

이 환경에는 프로덕션 접속 문자열이 오지 않습니다. 자동 백업 주기나 보관 기간은 데이터베이스 안내가 말하지 않으므로 여기서 단정하지 않습니다. 앱이 살아있는 동안 데이터베이스 비용이 있습니다. 그 밖의 유료 서비스는 쓰지 않습니다.

관리자는 `GET /api/admin/export`로 JSON을 받습니다. 파일에는 Cursor 식별자가 들어 있으므로 팀 밖에 두지 마세요. `POST /api/admin/import`는 같은 id를 덮어쓰지 않고 없는 행만 넣습니다. 작업을 지우지 않습니다. 화면에서는 휴지통과 복원만 있고 영구 삭제는 없습니다.

첨부 파일 저장소는 없습니다. 관련 주소는 http와 https만 저장합니다.

## 로컬 실행

```bash
npm install
npm test
npm run dev
```

`DATABASE_URL`이 없으면 메모리 Postgres(PGlite)를 씁니다. 이 데이터는 게시된 데이터베이스가 아닙니다. 로컬 화면의 사람은 시뮬레이션된 뷰어입니다. 다른 데이터베이스로 향하는 `DATABASE_URL`이 있다면 빼고 실행하세요.

```bash
env -u DATABASE_URL npm run dev
```

## 테스트

```bash
npm test
```

두 구성원이 같은 작업을 보고, 비구성원은 거절되고, 멤버는 관리자 API를 부르지 못하고, 봇은 담당·기한·완료·삭제를 하지 못하며, 반복과 알림 재시도는 중복되지 않고, 버전 충돌은 409이며, 빈 지연 사유 보고서에는 `사유 미입력`과 작업 id가 있는지를 확인합니다.
