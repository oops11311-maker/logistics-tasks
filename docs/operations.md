# 물류자동화 업무 운영

이 문서는 코드와 이 환경에서 확인한 사실만 적습니다. 앱은 이 작업에서 배포하지 않았습니다.

## 로그인과 초대

배포된 앱은 private 또는 team으로 열리도록 만들어졌습니다. 로그인 화면과 비밀번호는 앱 안에 없습니다. 누가 들어올 수 있는지는 Cursor 앱 게이트가 정하고, 앱은 그 요청의 서명된 신원으로 멤버를 찾습니다.

처음 관리자는 oops11311@gmail.com만 됩니다. 다른 사람은 초대되기 전에는 관리자가 되지 않습니다. Cursor 팀 역할은 앱 역할이 아닙니다. API 키는 멤버로 만들지 않으며 사람 권한을 받지 않습니다.

관리자는 관리 화면에서 이메일로 초대합니다. 그 이메일로 Cursor에 로그인한 사람만 멤버가 됩니다. 초대되지 않은 사람은 업무를 읽을 수 없습니다. 역할 변경, 비활성화, 프로젝트, 담당 지정, 완료, 삭제는 서버가 역할로 거절합니다.

로컬 `npm run dev`는 `cursor/identity.dev.js`의 시뮬레이트된 뷰어입니다. 이름은 Dev Viewer, 이메일은 dev@example.com입니다. 이것은 실제 로그인이 아닙니다.

## PWA

`app/manifest.ts`가 매니페스트를 만들고, 아이콘은 `public/icons/icon-192.png`, `public/icons/icon-512.png`입니다. 브라우저가 `beforeinstallprompt`를 주면 헤더에 **앱 설치**가 나옵니다. 그렇지 않으면 **홈 화면에 추가** 안내만 보입니다. iOS 설치는 이 환경에서 확인하지 않았습니다.

`public/sw.js`는 아이콘과 매니페스트만 캐시합니다. `/api/` 응답과 GET이 아닌 요청은 캐시하지 않습니다.

## 비밀값

이름만 바인딩되어 있습니다. 값은 이 환경에 없습니다. 사용자가 Cursor의 보안 입력으로 넣어야 봇 API와 스케줄 웹훅이 동작합니다.

- `BOT_API_TOKEN`: `POST`와 `GET /api/bot/...`의 헤더 `x-cursor-app-token`
- `SCHEDULER_TOKEN`: `POST /api/jobs/webhook`의 같은 헤더 이름

두 값이 없으면 해당 경로는 503입니다. 사람 화면은 이 값 없이 동작합니다. 사람 화면 요청에 앱 토큰이 있으면 403입니다. 토큰은 프론트엔드, URL, 로그에 넣지 않습니다.

## 스케줄

무인 스케줄은 켜져 있지 않습니다. 배포된 Cursor 앱이 서버 크론을 실행한다는 사실은 확인되지 않았고, 브라우저 타이머로 대신하지 않습니다.

같은 작업은 두 가지로 실행합니다.

- 관리 화면의 **지금 실행**
- `POST /api/jobs/webhook`에 `x-cursor-app-token: $SCHEDULER_TOKEN`과 선택적 `Idempotency-Key`

반복 발생과 알림은 키로 한 번만 만들어집니다. 실행 기록, 재시도 횟수, 마지막 성공, 다음 예정 시각은 관리 화면에 나옵니다. 실패했거나 예정 시각이 지났으면 경고가 보입니다. 코디네이터가 외부 루틴을 웹훅에 붙이기 전까지 작업은 자동으로 돌지 않습니다.

기본 주기(관리자가 바꿀 수 있음): 평일 09:00 오늘·지연 요약, 마감 1영업일 전 알림, 지연 알림, 진행 중 3영업일 미갱신, 목요일 15:00 주간 초안. 영업일은 월–금입니다. **공휴일 제외**는 기본 꺼짐입니다.

## 백업, 복구, 업데이트

`cursor-app.json`이 Postgres를 선언합니다. 배포하면 플랫폼이 `DATABASE_URL`을 넣습니다. 이 환경은 그 주소를 받지 않습니다.

자동 백업과 보관 기간은 Cursor Apps Postgres 문서에서 확인되지 않았습니다. 복구 절차를 제공한다고 말하지 않습니다.

스키마는 `migrations/001_init.sql`입니다. 배포 빌드의 `npm run build`가 `node scripts/migrate.mjs`를 실행하고, 적용된 파일 이름을 `schema_migrations`에 남깁니다. SQL은 업무 행을 지우거나 통째로 다시 만들지 않습니다. 로컬에서 `DATABASE_URL` 없이 `npm run migrate`를 실행하면 `migrate: nothing to do`입니다.

업데이트는 새 빌드를 배포하는 일입니다. 이 작업은 배포하지 않았습니다.

## 비용과 계정

데이터베이스는 앱이 존재하는 동안 과금된다는 점만 확인했습니다. 금액은 확인하지 못했습니다. 유료 제3자 서비스는 넣지 않았습니다. 푸시와 외부 메신저는 없습니다. 알림은 앱 안 수신함입니다.

## 된 것과 되지 않은 것

된 것:

- 업무, 프로젝트, 댓글, 멘션, 체크리스트, 관련 URL, 담당·마감·상태 기록
- 검색, 필터, 일괄 상태·담당, 낙관적 동시성(409)
- 반복 업무(일·주·월)와 중복 없는 재시도
- 역할 검사, 봇의 완료·재배정·마감 변경·삭제 거절

- 8초 간격 폴링으로 다른 사람의 변경 알림
- PC 왼쪽 메뉴와 모바일 하단 메뉴

확인하지 못한 것:

- 실제 여러 기기에서의 동시 사용
- 실제 푸시
- 무인 크론. 현재 꺼져 있음
- 프로덕션 Postgres에서의 프로세스 재시작. 로컬 파일 PGlite 재시작만 테스트함
- 배포된 Cursor 로그인. 로컬은 시뮬레이트된 뷰어
- iOS 홈 화면 설치
